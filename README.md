# DTE Integrations Landing Page - WORKING VERSION

## ✅ TESTED AND WORKS

This version uses Tailwind v3 (stable) and has been build-tested.

---

## 🚀 Quick Start

1. **Extract the archive:**
   ```powershell
   tar -xzf dte-integrations.tar.gz
   cd dte-landing
   ```

2. **Install dependencies:**
   ```powershell
   npm install
   ```

3. **Run locally:**
   ```powershell
   npm run dev
   ```
   Open http://localhost:5173

---

## 📦 Deploy to Vercel (5 minutes)

1. **Push to GitHub:**
   ```powershell
   git init
   git add .
   git commit -m "DTE Integrations landing page"
   git remote add origin https://github.com/DTE-84/DTEIntegrations.git
   git push -u origin main
   ```

2. **Deploy:**
   - Go to vercel.com
   - Click "New Project"
   - Import your DTEIntegrations repo
   - Click "Deploy" (Vercel auto-detects Vite)
   - DONE - live in 2 minutes

3. **Custom domain:**
   - Project Settings → Domains
   - Add `dte-solutions.icu`
   - Update DNS (add CNAME to Vercel)
